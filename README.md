# Scale Center — présentation et maquette

Support de la session **Salesforce Scale Center** présentée au Developer Group.

> ⚠️ **Toutes les données sont fictives.** Les deux organisations (Watt De France et EnGénie Mutuelle), leurs classes Apex, leurs chiffres et leurs captures sont inventés. Les écrans viennent d'une maquette HTML qui imite Scale Center, pas d'une vraie org.

## Contenu

| Dossier | Quoi |
|---|---|
| `deck/slides.html` | Les slides (Reveal.js, fonctionnent hors ligne) |
| `maquette/index.html` | La maquette interactive de Scale Center (HTML/JS, hors ligne) |

## Utilisation

Ouvrir directement les fichiers dans un navigateur (Chrome ou Edge) : aucune installation, aucun serveur.

**Slides** — `deck/slides.html`
- `→` / `←` ou espace : avancer / reculer (beaucoup d'éléments apparaissent au clic)
- `O` : sommaire en vignettes
- `S` : vue présentateur (notes)
- `Échap` : vue d'ensemble

**Maquette** — `maquette/index.html`
- Le menu de gauche reproduit celui de Scale Center ; le bouton « Changer d'org » (touche `O`) bascule entre les deux orgs fictives.
- Barre du présentateur en bas : `Fil 1` / `Fil 2` rejouent les deux enquêtes étape par étape (`→` `←`, `1`-`9`), `?` affiche l'aide des raccourcis.
